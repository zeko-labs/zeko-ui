# Using Zekoscan Explorer

[Zekoscan](https://zekoscan.io/) lets you view transactions, blocks, and account activity on the Zeko network. Use it to track your activity and explore the chain.

## What To Search

- account addresses
- transaction hashes
- block information

## Common Checks

- Confirm that a transaction was included.
- Review recent activity for an account.
- Verify that a dapp or bridge action changed account state as expected.
- Share an explorer link when asking for support.

Explorer indexing can lag behind the latest network state. If a wallet or dapp just submitted a transaction, wait briefly and refresh before assuming the transaction is missing.
