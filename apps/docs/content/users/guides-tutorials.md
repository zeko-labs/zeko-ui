# Guides & Tutorials

Use these guides for common user flows on Zeko.

- [Sending Tokens](./guides/sending-tokens.md) - send MINA or test MINA from a wallet on the selected Zeko network.
- [Interacting with a Dapp](./guides/dapp.md) - connect a wallet, review permissions, sign transactions, and confirm activity.
- [Using Zeko Bridge](./guides/zeko-bridge.md) - move assets between Mina L1 and Zeko L2.
- [Using Zekoscan Explorer](./guides/zekoscan-explorer.md) - look up transactions, blocks, and account activity.

If you are new to Zeko, start with [Getting Started](./getting-started.md) before using these guides.
