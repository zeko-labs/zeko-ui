# Contributing to Zeko Development

We welcome contributions from the community! Whether you're fixing bugs, improving documentation, or proposing new features, your help is appreciated.

## Repository Links

- **Main Zeko Repository**: [github.com/zeko-labs/zeko](https://github.com/zeko-labs/zeko)
- **Zeko UI & Apps Repository**: [github.com/zeko-labs/zeko-ui](https://github.com/zeko-labs/zeko-ui)

## Community Support

Join our community channels to get help, share ideas, and collaborate with other developers:

- **[Zeko Discord](https://discord.gg/edF9vzD7en)**: Primary community chat for Zeko developers and users
- **[Mina Discord](https://discord.com/invite/minaprotocol)**: Broader Mina Protocol community resources

## How to Contribute

### 1. Find an Issue or Create One

Browse the [issues](https://github.com/zeko-labs/zeko-ui/issues) on GitHub to find something to work on, or create a new issue to propose a feature or report a bug.

### 2. Fork and Clone

Fork the repository and clone it to your local machine:

```bash
git clone https://github.com/YOUR_USERNAME/zeko-ui.git
cd zeko-ui
```

### 3. Set Up the Development Environment

Follow the setup instructions in the repository's `README.md` to install dependencies and configure your environment.

### 4. Make Your Changes

Create a new branch for your work:

```bash
git checkout -b feature/your-feature-name
```

Make your changes, following the project's coding standards and conventions.

### 5. Test Your Changes

Ensure your changes work as expected and don't break existing functionality. Run tests if available.

### 6. Submit a Pull Request

Push your changes to your fork and open a pull request to the main repository. Provide a clear description of your changes and reference any related issues.

## Areas for Contribution

- **Documentation**: Improve guides, fix typos, add examples
- **Bug Fixes**: Resolve issues reported in the issue tracker
- **Features**: Implement new functionality discussed in issues
- **Testing**: Add or improve test coverage
- **Developer Tools**: Build tools to improve the developer experience

## Code of Conduct

Please be respectful and constructive in all interactions. We aim to maintain a welcoming and inclusive community.

Thank you for contributing to Zeko! 🚀
