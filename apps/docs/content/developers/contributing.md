# Contributing to Zeko Development

:::warning
WIP: This section is under construction.

Contributions are welcome! Fork the repo, open a pull request, and join the Zeko developer community.

- [Zeko GitHub repository](https://github.com/zeko-labs/zeko) – source code for the Zeko protocol, including the sequencer and data availability components.
- [Zeko Discord](https://discord.gg/edF9vzD7en) – the primary community hub for developers and contributors.
