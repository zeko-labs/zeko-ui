# Examples & Boilerplates

Browse ready-to-use code examples and boilerplate projects to kickstart your Zeko development.

## Quick Start Resources

For general guidance on getting started with Zeko development, refer to the [Quick Start Guide](../introduction/quick-start.md) and [Developer Getting Started](./getting-started.md) sections.

## Code Examples

### LuminaDex Integration

- **[LuminaDex SDK](https://sdk.luminadex.com/)**: Library for integrating DEX functionality into your application
- **[LuminaDex Contracts](https://github.com/Lumina-DEX/lumina/tree/main/packages/contracts)**: Audited smart contracts for decentralized exchange
- **[LuminaDex UI Source](https://github.com/Lumina-DEX/lumina/tree/main/packages/dex-ui)**: Complete frontend implementation example

### Token Development

- **[Mina Fungible Token Standard](https://github.com/MinaFoundation/mina-fungible-token)**: Reference implementation for custom tokens on Mina/Zeko

### Interactive Demos and POCs

- **[zkApp Question Proof Demo](https://github.com/RaidasGrisk/zkapp-ui)**: Prove you know the answer to a question (10 / 2 + 2 = ?)
- **[Off-chain Voting POC](https://github.com/Trivo25/offchain-voting-poc)**: Proof of concept for off-chain voting systems
- **[Cryptographic Proof of NFT Endorsement](https://github.com/racampos/cpone)**: CPONE - NFT endorsement verification

### Development Tools

- **[easy-mina-deploy](https://github.com/MinaPlayground/easy-mina-deploy)**: Deploy smart contracts with one command by specifying your contract and keys
- **[zkApp CLI](https://github.com/o1-labs/zkapp-cli)**: Official command-line tool for scaffolding and managing zkApp projects
