# Zeko Core Concepts

:::warning
WIP: This section is under construction. Content is for illustrative purposes only.
:::

Zeko uses zk-rollups for scalability, zero-knowledge proofs for privacy, and zkPrograms for smart contracts. State transitions are handled off-chain and verified on Mina.

```d2
UserTx -> Sequencer -> Prover -> Mina (Verifier)
```
