# Architecture

Use this file only when the user asks how Zeko works internally.

## Short version

- Zeko is a Mina-oriented zkRollup.
- The sequencer coordinates state transitions and commits rollup state.
- The bridge moves assets between Mina and Zeko with deposit and withdrawal proofs.
- The DA layer provides availability guarantees for rollup data.
