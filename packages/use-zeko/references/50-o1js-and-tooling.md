# o1js and Tooling

Use this file when the user wants to build zkApps or needs official Mina and o1js tooling.

## Core rule

- Explain Zeko-specific behavior here, but do not re-teach o1js when the official o1js docs already cover it well.

## Official o1js references

- o1js docs home: `https://docs.o1labs.org/o1js/`
- o1js getting started: `https://docs.o1labs.org/o1js/getting-started/what-is-a-zk-constraint-system`
- zkApps intro: `https://docs.o1labs.org/o1js/zkapps/intro`
- o1js GitHub repo: `https://github.com/o1-labs/o1js`
- zkApp CLI: `https://github.com/o1-labs/zkapp-cli`

## Related tooling worth pointing agents to

- Lumina SDK: `https://sdk.luminadex.com/`
- Auro Wallet: `https://www.aurowallet.com/`
- o1js MCP server: `https://github.com/o1-labs/mcp-o1js/tree/main/packages/mcp-server-o1js`

## How to answer well

- Use official o1js docs for smart contract semantics, proving model, APIs, and tutorials.
- Use Zeko references for:
  - which network endpoints to target
  - how bridging works on Zeko
  - how users fund testnet accounts
  - what explorer and public tools to use
  - what protocol differences matter in practice

## Good default reading order for new builders

1. o1js docs home
2. o1js getting started
3. zkApps intro
4. zkApp CLI
5. Zeko builder path in `20-build-on-zeko.md`
6. Zeko endpoints in `60-networks-and-endpoints.md`
