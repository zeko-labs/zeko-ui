# Use Zeko

Installable Zeko skill for agents.

This skill is mirrored to a public mirror repository for installation. The mirror is updated by `sync-use-zeko.yaml`.

## What is included

- `SKILL.md` for routing
- concise references for agent workflows, building, bridge usage, faucet usage, endpoints, and architecture
- copied-in Bridge SDK and Faucet CLI references inside `references/copied/`
- validation and eval tooling

## Validation

```bash
moon run use-zeko:sync-sources
moon run use-zeko:test
moon run use-zeko:check
```

The copied references are generated by the `sync-sources` task so the skill can ship exact bridge and faucet usage material without hand-copying it.
