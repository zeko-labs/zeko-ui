# Use Zeko

Use this skill when the user wants to use Zeko as an end user or build on Zeko as an app developer.

Core rules:

- Prioritize public user and builder workflows over contributor workflows.
- Treat Zeko as `o1js`-first. Use official o1js docs for framework semantics, and use Zeko sources for Zeko-specific deltas.
- Prefer canonical files and live public docs over stale sidebar assumptions or example scripts.
- When exact endpoints or live app availability matter, verify them against [references/60-networks-and-endpoints.md](references/60-networks-and-endpoints.md) and the mapped authority chain in [references/99-source-of-truth.md](references/99-source-of-truth.md).
