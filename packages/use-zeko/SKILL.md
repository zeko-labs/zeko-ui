# Use Zeko

Use this skill when the user wants to use Zeko or build on Zeko.

Defaults:

- For agents, prefer private keys and environment variables.
- Only talk about Auro Wallet when the agent is driving a browser with extension access.
- Default to testnet and gateway-backed endpoints in `references/50-endpoints.md`.
- Use the bundled copied references for exact Bridge SDK and Faucet CLI syntax.
- Zeko can be built with `o1js` or directly with OCaml contracts and protocol code.
